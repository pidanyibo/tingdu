# 听读 Tingdu

一个轻量的离线音频文字播放器。导入录音和带时间戳的文稿，播放时自动高亮当前段落。

单个 HTML 文件，无需安装、注册或联网。

## 功能

- 支持浏览器可播放的音频格式，如 MP3、WAV、M4A
- 支持 TXT 和 Word DOCX 文稿
- 根据已有时间戳整段高亮
- 点击段落跳转播放
- 支持倍速、前后跳转和字号调整
- 自动跟随滚动，也可暂停跟随、自由翻阅
- 文件在本地读取，不上传音频或文稿

## 使用方法

1. 点击本页上方绿色的 Code → Download ZIP。
2. 解压下载的压缩包。
3. 使用新版 Edge 或 Chrome 打开“离线听读.html”。
4. 分别选择音频和对应文稿。
5. 点击播放，即可跟随文字阅读。

也可以先点击播放器里的“静音示例”体验高亮效果。

## 文稿格式

每段前需要有开始时间，例如：

```text
Speaker 1 00:00:20.670
这里是第一段正文。

Speaker 1 00:01:45.230
这里是第二段正文。
```

也支持 `01:20`、`[01:20]` 等时间格式。

## 使用说明

- 按现有时间戳整段高亮，不进行语音识别或逐字对齐。
- 本段持续高亮到下一段开始，最后一段持续到音频结束。
- DOCX 只读取文字，不保留原排版；旧版 DOC 请先另存为 DOCX。
- 刷新或关闭页面后，需要重新选择文件。
- 点击 GitHub 上的 HTML 文件会显示源代码，请下载后在浏览器中打开。
